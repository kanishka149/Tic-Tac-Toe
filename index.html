🎮 About the App

Tic Tac Toe is a two-player game where players take turns placing X and O on a 3×3 grid. The player who gets three symbols in a row, column, or diagonal wins the game.

✨ Features

  • Two-player gameplay
  • 3×3 game board
  • Automatic winner detection
  • Draw detection
  • One-tap game reset
  • Live game status

⚙️ How It Works

Player X starts the game by selecting an empty cell. Player O then takes the next turn. After every move, the game checks all possible winning combinations. If a player gets three symbols in a row, the game announces the winner. If all cells are filled without a winner, the game ends in a draw.

💻 Technology
